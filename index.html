Summary

I am a Senior Architect at AWS Professional Services. Before that, nineteen years of C# and .NET, most of it with my hands on the keyboard. For the last four years the work has been application modernization with generative AI: .NET off Windows and onto Linux containers, and COBOL mainframe systems turned into .NET services using AWS Transform, Amazon Bedrock, Strands Agents and Kiro.

I also build and run agentic systems in production on Amazon Bedrock AgentCore: runtime, gateway, memory, identity, observability. A demo agent and a production agent are not the same thing. The difference is guardrails, evaluation, and being able to answer what the agent actually did when someone asks you six weeks later. Long background in healthcare (HL7, FHIR), banking and insurance, and years of leading distributed teams of 10+ engineers.

I write for the .NET on AWS Blog, review AWS drafts, and post about this work on my blog and on LinkedIn. I write those myself. Certified across AWS, Azure and Google Cloud (Solutions Architect Professional, ML Specialty, Azure Solutions Architect Expert, Professional Cloud Architect). AWS is where I actually work.
