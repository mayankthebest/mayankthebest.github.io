# mayankthebest.github.io

My résumé. Plain HTML, CSS and JavaScript. No framework, no build step, no dependencies.

Live at [mayankthebest.github.io](https://mayankthebest.github.io/).

## Deploying

Push to `main`. GitHub Pages serves the root of the default branch.

## Fonts

Inter and JetBrains Mono come from Google Fonts. Offline, both fall back to system fonts
and the page still renders correctly.
